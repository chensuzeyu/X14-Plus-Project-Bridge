## 与初始计划的调整

- MCP 层用 JavaScript ES modules 编写，使用相同的官方 SDK，减少额外编译依赖。
- 搜索先用有时间/结果预算的 Python 字面文本扫描，避免依赖 Codex 附带的 rg；大型代码库可后续增加独立 ripgrep。
- 补丁采用唯一字符串替换或完整文件写入；不是通用 unified-diff 导入器。返回 unified diff 供审查。
- 删除文件已包含在 apply_changes 中；移动文件、Git 提交等可通过已授权命令执行，目前未另设专用工具。
- Windows 官方隧道客户端、本地 HTTP + 额外认证头、云端请求透传和个人账号权限均已通过真账号测试。
