# 本地项目图片工具

实现日期：2026-09-21。本文保留第一版设计与故障记录。当前范围和大小限制以 [本机跨项目图片读取](14-local-image-access.md) 为准；正式工具已有网页截图识读及任务后续编辑反馈，验收边界见 [任务内自主读图验收](13-task-vision-acceptance.md)。此前三个固定样本开启图片引用的识图结果均正确（27/27）。

## 使用

对网页 GPT 说：“查看 bridge 项目的 tmp/image-viewer-acceptance/web-experiment.png，解释截图里的实验状态。”

工具输入示例：

```json
{"project_id":"bridge","paths":["tmp/image-viewer-acceptance/web-experiment.png"],"question":"解释截图中的实验状态，说明哪些阶段已经完成。"}
```

项目 ID 不明时先 list_projects；路径不明时 list_files。路径明确后直接 view_project_images，无需通过 read_files 读取二进制图片，也不使用 OCR 代替网页模型的视觉。使用说明已经加入 MCP 服务 instructions 和工具描述；不要求用户另装 skill。网页刷新工具定义后生效。

首次回复应简短说明正在准备图片；卡片自动完成上传、图片引用及一次 ui/message 续答。图片准备与视觉回答仍是两个轮次，无法承诺宿主隐藏所有中间消息。用户分析问题及图片顺序映射会进入续答。模型应根据实际视觉回答，不能把上传成功当作识图成功。

## 第一版范围

- 仅已配置的本地项目，PNG/JPEG，1–4 张不同路径。SSH、PDF、Excel 暂不支持。
- 支持项目相对路径，以及所选项目内的完整磁盘路径（正反斜杠均可）；完整路径先转换为相对路径，再复用 Engine 校验，拒绝项目外路径、上级跳转、凭据目录及链接/junction。
- 单张源文件最多 20 MiB、2500 万像素；长边最多 2048，传输单张最多 640 KiB。超出传输限制时等比例进一步缩小，不裁剪；动画 PNG 拒绝。
- 小图无需处理时保留原字节；JPEG 重编码质量 85，EXIF 方向按需纠正。返回原始/输出尺寸、哈希、resized、recompressed 等字段；卡片显示修改情况。细小文字不清时不能猜测。
- 依赖配置中的 Python 已安装 Pillow；缺失时明确报 IMAGE_DEPENDENCY_MISSING。
- MCP 可见结果只有路径、尺寸、状态及用户问题；Base64 和领取许可放在 UI 私有 _meta。无 GitHub 中转或额外图片托管。

## 重复执行和失败处理

claim_image_delivery 是 UI 专用内部工具，默认不向模型展示。每次图片结果有随机 run_id 与私有 token；状态目录保存少量领取记录，不保存图片副本。UI 校验字节后领取一次性上传许可，服务使用排他文件创建保证同一 run_id 只允许一个实例提交；并发进程也受约束。记录 24 小时后不再接受领取，当前版本不自动清理历史记录。

同一实例重复通知不上传、不续答。恢复到已开始的记录不重试；状态丢失仍由服务领取记录阻止重复上传。若上传/续答超时或部分成功，会停止并展示阶段及错误；不盲目重试。此策略优先避免重复，不能保证失败时自动恢复。用户明确发起新请求会产生新的 run_id，允许重新读取。

运行详情包含上传和续答尝试次数、文件 ID、事件时间、重复通知数，不记录 Base64 或私有领取 token。工具批次中任何图片预处理失败，整批报错；不会悄悄漏掉失败图片。

## 验收

真实网页待验收：刷新插件出现 view_project_images；用上方真实截图路径调用；只发一次提示词，等待自动视觉回答；展开运行详情应有 upload_attempts=1、followup_attempts=1。点击检查重复通知后两值应不变、不触发新回答。文件不存在/格式不支持在服务测试中验证，网页可按需抽查。

CSP：资源声明空外部连接/资源域名白名单。需在网页宿主开启 CSP 时复测。界面的“CSP 关闭”是宿主状态，本工具不会主动关闭它；当前不宣称已通过 CSP 开启验收。
