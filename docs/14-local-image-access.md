# 本机跨项目图片读取

本页取代第 12 篇的项目范围及大小限制说明。

- `view_project_images` 保留原名称兼容现有调用。绝对路径可位于任意本地磁盘，不需要 project_id；相对路径仍需指定本地项目。
- `discover_local_images` 不需项目参数。省略 path 返回本地磁盘和用户主目录；指定绝对目录返回子目录和 PNG/JPEG 路径。可按文件名 contains 搜索，recursive 默认 false。
- 搜索最多遍历 20000 项或 8 秒。scan_truncated 表示未查完，应缩小目录；has_more/next_offset 仅对本次扫描到的图片分页。目录变化时不保证分页快照。无权限项和链接会跳过并计数。子目录列表最多 200 项。
- 已知图片位置直接读图，无需先搜索。未知位置逐步缩小范围；不得把文件名搜索当作图像内容识别。
- 图片通过原卡片上传、图片引用和自动续答管线进入视觉上下文，续答继续原任务。

## 限制

每批 1–4 张，单张原文件 32 MiB、4000 万像素。PNG/JPEG 单帧；自动处理 EXIF 方向。传输最长边 2560 像素、每张 768 KiB；复杂图片可能继续缩小以适应体积。四张 Base64 加元数据仍在既有 5 MB 子进程输出限制内。

范围是服务账户可访问的本机磁盘，不能绕过操作系统权限。网络路径、映射网络盘、设备路径及链接/目录联接不支持，应提供真实本地目标路径。此扩展只增加图片读取和目录发现能力，现有普通文件读写工具仍按项目边界工作。

## 验证

自动化覆盖项目外图片不带 project_id 读取、中文路径、目录发现、链接跳过、相对路径缺项目拒绝、网络路径拒绝、超过旧 20 MiB 限制的文件读取、超过 32 MiB 拒绝、3000 万像素图片读取，以及原有上传去重和错误交接。

网页端仍需刷新插件确认新参数与工具。服务验证不等同于网页实际视觉验收。
