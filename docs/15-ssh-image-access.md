# SSH 图片读取

## 使用方式

继续使用 `view_project_images`，不增加模型工具。指定已配置的 SSH `project_id`，paths 支持项目内相对路径及项目根目录内的绝对路径。例如：

```json
{
  "project_id": "volcengine-cszy",
  "paths": ["/Knowin/sim/chensuzeyu/tmp/RIT1.png"],
  "question": "根据实际可见图片提取原任务所需信息，再继续原任务。"
}
```

未知位置使用 `list_files` 在远程项目内查找；`discover_local_images` 仍只查本机。本机绝对路径不带 project_id 的用法不变。SSH 图片目前限于配置的项目范围，不是远程全盘访问；拒绝父目录跳转、链接、私密目录和项目外绝对路径。

## 管线与依赖

SSH 通过标准库读取原图 → 本机 Pillow 校验、方向处理及必要的缩放压缩 → 原有卡片上传、imageIds 和自动续答。远端无需 Pillow，无需修改原图或安装新包；使用原有远端 engine.py 的路径校验。读取辅助代码随请求执行，不持久安装到远端。

每批 1–4 张，原图每张最多 32 MiB、4000 万像素。原图按张读回，SSH 读取输出上限单独设为 46,000,000 字符以容纳 Base64；其他命令输出仍是原来的 5,000,000 字符上限。每张最终图片仍最多 768 KiB、最长边 2560 像素。大量或大尺寸原图会增加 SSH 传输与准备时间。

图片数据在内存中处理；交付记录不写入原图。返回 `source_target` 标识来源主机，自动续答保留主机、图片顺序与路径。卡片资源升级为 `ui://x14/project-images-v5.html`。
