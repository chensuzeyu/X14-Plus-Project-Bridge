## 3. 使用过的历史背景

2026-09-19 的已有记录显示，用户曾要求把代理转发恢复到 SSH Host 配置，并撤回额外隧道守护方案。本规划沿用这一架构偏好；这次已重新核实 Host 中的转发配置。

历史记录里“旧启动项已删除、专用进程已停止”等信息，本轮未重新全面核查，因此不作为当前系统状态结论。历史上的 SSH/HTTP/WebSocket 故障结果也不代表今天的链路状态。

## 4. 未验证且必须在实施中解决的事项

1. 目标 ChatGPT 套餐、工作区、开发者模式和 Tunnel 入口是否实际可用。
2. Platform 组织的 Tunnels 权限、ChatGPT 工作区关联及运行时凭据配置。
3. 官方 tunnel-client 当前 Windows 构建、安装方式、出站代理配置及实际网络可达性。
4. 隧道相关计费、限额和账号策略；不能承诺免费或无限制。
5. 用户最终授权的本地项目列表、远程子项目列表和是否开启主机级命令。
6. 火山引擎当前 SSH 可达性、远端目录权限、Python/Git/搜索工具和任务运行条件。
7. 远端 19081 当前监听者及关闭 Codex 后的转发生命周期。
8. ChatGPT 对写工具的实际确认行为、调用时长和结果大小限制。
9. 私有 Tunnel 连接下业务身份映射和授权方式；公网 OAuth 时授权服务器的可达性。
