# 混合来源任务验收

## 默认流程

服务 instructions 和 view_project_images 说明共同指导路由：依据配置中的项目根目录、目标主机及引用资料来源，不凭文件名或路径开头猜主机。资料中的相对附件以资料目录为基准，继承主机和项目。未知位置使用本机图片发现或 SSH 项目文件列表；有歧义先核对上下文，连接失败不改读另一主机同名文件。

每批只包含同一来源主机/项目的图片。等待当前批自动续答后，再读取其他必要证据；问题上下文应保留任务目标、已确认结论、待办步骤、允许修改的输出路径和读回要求。卡片 v6 续答明确继续收集证据、完成原任务并读回验证。工具数量不变，无需用户额外安装 skill。
