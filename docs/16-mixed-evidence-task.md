## 默认流程

服务 instructions 和 view_project_images 说明共同指导路由：依据配置中的项目根目录、目标主机及引用资料来源，不凭文件名或路径开头猜主机。资料中的相对附件以资料目录为基准，继承主机和项目。未知位置使用本机图片发现或 SSH 项目文件列表；有歧义先核对上下文，连接失败不改读另一主机同名文件。

v7 优先把最多 4 张必需图片通过 sources 参数一次请求，允许混合本机与 SSH 项目。每张图片保留自己的主机、项目、路径及全局顺序。全部准备成功才创建交付，不发布半批图片；同一卡片统一上传、引用后只发一次续答。旧 paths/project_id 调用仍兼容，不能与 sources 混用。工具数量不变，无需用户额外安装 skill。

```json
{"sources":[{"project_id":"bridge","path":"tmp/mixed-evidence-task-v2/evidence/RIT1.png"},{"project_id":"volcengine-cszy","path":"tmp/RIT1.png"}],"question":"保留原任务目标与剩余文件修改、最终读回要求。"}
```

问题上下文应保留任务目标、已确认结论、待办步骤、允许修改的输出路径和读回要求。续答要求逐张判断可见性；必需证据未取得时报告部分完成。最后一次写入（含修正）后必须重新读取全部输出。这些是模型执行指引，不能当作已经实现的强制任务状态机或视觉验证。
